Entry for [The Absurd Clause Contest](https://make.fun/c/u-donrulezz-the-absurd-clause-contest-035cc0f1)
on [make.fun](https://make.fun): one original English sentence of at most
200 characters, phrased as an absurd clause buried deep inside a
terms-of-service agreement.

## The clause

> By using this service, you agree to leave one (1) sock outside your front
> door on the first Tuesday of each month for collection by the Company's
> sock gnome.

(157 characters, one sentence.)

## How it works

`main.py` is a deterministic Python program — no network, no randomness.
It writes the clause to `/output/entry.txt` and includes a self-check gate
(length 1–200 characters, single line, no control characters, valid UTF-8)
before writing.

```sh
python3 main.py
cat /output/entry.txt
```
